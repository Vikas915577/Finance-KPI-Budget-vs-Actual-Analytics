GITHUB PAGES PAR UPLOAD KARNE KE STEPS

1. ZIP ko extract karein.
2. Extracted folder ke ANDAR ka content repository ke root mein upload karein (poora folder ek extra nested folder ke andar na daalein).
3. Ensure karein ki index.html repository ke root mein hai.
4. Existing repo ke purane project files ko delete karne se pehle compare karein; is ZIP mein project ki complete file structure included hai.
5. GitHub > Settings > Pages mein main branch aur /(root) source select karein (agar GitHub Pages use kar rahe hain).
6. Actions tab mein deployment successful hone ka wait karein.
7. Site ko hard refresh/private tab mein khol kar check karein.
8. Agar GitHub integration direct write block kare, to browser se files upload/replace karke commit karein. Is environment se repository par direct push ki guarantee nahi hai.

python -m pip install -r requirements.txt
